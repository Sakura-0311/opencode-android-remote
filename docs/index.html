免局域网配网 · 账号/配对码即时中继

告别以往需要手机和电脑连入同一个家庭 Wi-Fi，或手动配置复杂内网穿透（frp/ngrok/端口映射）的噩梦。电脑端启动时生成专属配对码，手机端输入相同账号即可打通安全长连接隧道。

📱

100% 原生体验

采用 Kotlin + Jetpack Compose 原生现代化渲染，无 WebView 卡顿，拥有丝滑的高帧率触控响应与 Material 3 沉浸式暗黑主题。

🔒

传输层加密与密钥鉴权

所有 AI 模型的 API Key 与你的工程代码均妥善保留在本地电脑。支持 TLS/WSS 传输层加密与 32 字节高熵 Secret 握手鉴权，中继服务器内置滑动窗口防爆破限流。

🚀

GitHub Actions 云端免配置自动打包

无需在本地安装数十 GB 的 Android Studio 与 SDK。项目内置 CI/CD 流水线，Fork 或推送代码到 GitHub 仓库后，云端将在 2 分钟内自动完成编译并产出开箱即装的 APK。
