## v5.1 实施清单

### 1. Backoff 加最大重试（`network/Backoff.kt`）
- 加 `maxRetries: Int = 10` 参数，加 `retryCount` 计数
- `nextDelayMs()` 返回 null（或抛）表示耗尽，调用方转 `Failed` 状态
- 成功后 `reset()` 清零计数
- 单测：`BackoffTest`（退避序列、耗尽、reset）

### 2. 手动重连入口
- `RelayWebSocketClient.reconnect()`：取消当前退避、reset 计数、立即重连
- ViewModel 转发；UI 在 Failed 状态显示「重新连接」按钮
- 文案：`reconnect_001` 等（十语言）

### 3. 网络切换主动重连
- `NetworkMonitor` 回调里：Wi-Fi↔移动数据切换时，若正在重连退避中，立即触发一次重连（不等待退避）

### 4. 状态机复核
- 全仓 grep `webSocket != null` 这类裸判断，统一走 `RelayConnectionState`
- 确认 UI 只订阅 `onConnectionStateChanged`，不各自拼状态

### 5. 回归测试补齐
- `BackoffTest`（纯 Kotlin，可 JVM 跑）
- `RelaySeqTracker` 已有；`RelayMessageParser` 已有
- 发送队列（v4.10.0 的 PendingSend）抽纯逻辑补单测
